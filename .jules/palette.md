## 2024-05-24 - Accessibility improvements for icon-only buttons
**Learning:** Added Portuguese `aria-label`s, native `title` tooltips, and `focus-visible` classes to icon-only buttons in the sidebar for screen readers and keyboard navigation.
**Action:** Always ensure that any added user-facing text, such as `aria-label`s or native tooltips, is written in Portuguese, as the application's user interface is in Portuguese (pt-BR).

## 2024-05-18 - Prevent SSRF and Injection in API Route Params\n**Vulnerability:** User-controlled parameters (phone IDs, versions) were directly interpolated into an external WhatsApp API URL without validation.\n**Learning:** Next.js backend proxy routes interacting with third-party APIs must strictly type and validate inputs to prevent Server-Side Request Forgery (SSRF) and injection attacks.\n**Prevention:** Apply strict regex validation to all path variables and query parameters before interpolating them into outgoing fetch requests.

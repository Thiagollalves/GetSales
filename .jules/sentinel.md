## 2024-05-18 - Hardcoded Fallback Credentials\n**Vulnerability:** Hardcoded admin credentials used as fallback when configuration is missing.\n**Learning:** Always restrict development fallbacks or bypasses to non-production environments to avoid accidental exposure if environment variables fail to load.\n**Prevention:** Use `process.env.NODE_ENV !== "production"` checks around dev-only fallback credentials and ensure secure failure modes when required configuration is missing in production.
